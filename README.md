# Warzone Turbo

A small, focused utility for Windows.

## About the project
Feature-rich **Warzone Turbo** competitive platform offering matchmaking stats, crosshair tools, and input optimization.

The goal is a tool that just works — no clutter, no bloat.

## Features
- **Anti-Cheat Compatible:** Designed to work alongside major anti-cheat systems safely.
- **Hardware Monitor:** CPU, GPU, RAM usage tracking with per-game performance history.
- **Auto-Config:** One-click optimal settings based on your hardware specifications.

## Before you start
- Windows (64-bit)
